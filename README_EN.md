# Key2Play 🎮

[한국어](README.md) | **English**

Key2Play is a **programmable one-key USB keyboard**. Enjoy games with just one button!

## 💻 Works with Multiple Devices

Key2Play works as a USB keyboard and can be used with **smartphones, laptops, and desktop computers**.

- 📱 **Smartphones** — Connect using USB-C or a compatible adapter
- 💻 **Laptops** — Connect via USB
- 🖥️ **Desktop computers** — Connect via USB

> Smartphones must support USB keyboard input (USB OTG), and some devices may require an adapter. **Using Key2Play as a keyboard** and **connecting it to the configuration website** are different capabilities; configuration connectivity depends on the operating system and browser.

### ⚙️ How to Play

1. Connect Key2Play to your computer.
2. Assign your preferred key using the Key2Play configuration software.
3. Launch a game and press the button to play!

> Controls and compatibility may vary by game. Some games require installation or purchase.
