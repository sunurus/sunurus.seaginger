# Key2Play 🎮

**한국어** | [English](README_EN.md)

Key2Play는 원하는 키를 설정할 수 있는 **원키 USB 키보드**입니다. 버튼 하나로 간편하게 게임을 즐겨보세요!

## 💻 다양한 기기에서 사용 가능

Key2Play는 USB 키보드처럼 작동해 **스마트폰, 노트북, 데스크톱** 등 다양한 기기에서 사용할 수 있습니다.

- 📱 **스마트폰** — USB-C 또는 호환 어댑터로 연결
- 💻 **노트북** — USB로 연결해 사용
- 🖥️ **데스크톱** — USB로 연결해 사용

> 스마트폰은 USB 키보드 입력(OTG)을 지원해야 하며, 기기에 따라 어댑터가 필요할 수 있습니다. 키보드 입력 기능과 **키 설정 웹사이트의 기기 연결 기능**은 별개이며, 설정 웹사이트의 연결 지원은 운영체제·브라우저에 따라 다릅니다.

## 🎮 Key2Play로 즐길 수 있는 게임 추천

### 🕹️ 1인용 게임

| 게임 | 추천 키 | 플레이 링크 |
|---|---|---|
| Geometry Dash | `Space` | [Steam](https://store.steampowered.com/app/322170/Geometry_Dash/) |
| Flappy Bird | `Space` | [바로 플레이](https://flappybird.io/) |
| Chrome Dino | `Space` | [바로 플레이](https://chromedino.com/) |
| Bits & Bops | 미니게임별 한 버튼 조작 | [Steam](https://store.steampowered.com/app/1929290/Bits__Bops/) |

**Chrome Dino:** Chrome 주소창에 `chrome://dino`를 입력해도 플레이할 수 있습니다.

### 👥 2인용 게임

**12 MiniBattles** — [게임 플레이하기](https://www.kiwigames.io/game/12-minibattles)

두 사람이 각각 Key2Play 하나씩 사용해 대결할 수 있습니다.

- **플레이어 1:** `A`
- **플레이어 2:** `L`

### ⚙️ 플레이 방법

1. Key2Play를 컴퓨터에 연결합니다.
2. Key2Play 설정 프로그램에서 원하는 키를 선택합니다.
3. 게임을 실행하고 버튼을 눌러 플레이합니다!

> 게임별 조작키와 지원 환경은 다를 수 있습니다. 일부 게임은 설치 또는 구매가 필요합니다.
